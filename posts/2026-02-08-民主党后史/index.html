民主党后史

February 8, 2026 · ​

1996~2017年，这二十年间叱咤日本政坛的二大政党，一为自民党，二为民主党。在此之后，实际也是如此。作为组织的民主党在2017年解体了，但是其中人物如何呢。历数民主党中坚：

小泽一郎 X

海江田万里 X

冈田克也 X

菅直人 X

野田佳彦

安住淳 X

近藤昭一 X

枝野幸男 X

前原诚司 国民

莲舫 参院

辻元清美 参院

马渊澄夫 X

玄叶光一郎 X

小川淳也 X

末松义规 X

逢坂诚二 X

长妻昭 X

如此氓氓。2017~2026年的十年间，民主党依旧作为一个幻影，活在日本政治中。民主党人虽然顶着不同的牌子，但是这三个字始终未变，萦绕在所有日政的参与者之中。不论是立宪民主党亦或者是国民民主党，都逃离不开那个20年间的幻梦。
直到今天，我们才见到了民主党的湮灭。而二十年+十年的漫长岁月，已经足够让民主党只剩下一滩模糊的泡影，成为不可追溯的历史的一部分。而得以存活下来的则是那些终于扭曲的。就如同特拉比松帝国一样，特拉比松是罗马吗？很难说得上是，但是如今也没人与他们争夺这一个名号。国民民主党就是这样一个扭曲，而民主党的确是死了。
